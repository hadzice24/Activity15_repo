# Activity15_repo

This is a repository that was created to practice what we learned about
Github and version control in STAT 184. I will add the files of Activity
14 and create a plan in this repository. It demonstrates branching, pull
requests, issues, and version control using GitHub and GitHub Desktop.

## Data
There are no data files associated with this repository.

However, the files from Activity 14 use the following datasets:

1.  **babynames data from the `babynames` package (dcdata)**
   
2.  **Armed Forces Data scraped data from two external web pages**

        Ranks](https://neilhatfield.github.io/Stat184_PayGradeRanks.html)
